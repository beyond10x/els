## The stop

The stage-1 wave proposal for wave 2026-10-07-w1 (`story:project-routes`).

## Why there was no stop

The request that asked for this work named it: publish `.well-known/b10x-routes.json`
(`b10x-project-routes/v1`) from `canon-engineering-docs site-manifest`, delivered as one wave on one
integration branch with one pull request. The work selected is exactly that request, so the
proposal had nothing left to choose. Tag `non-interactive`: the coordinator had no operator turn to
stop at.

## Decided

- One unit, `story:project-routes`, serving `vision:O2`.
- Route rules follow `beyond10x/secrets` `crates/secrets-docs/src/routes.rs` (Docusaurus,
  `trailingSlash: false`, same docs-system pin) rather than metaharness's hand-rendered-site
  producer; the document shape is identical.
- Not modelled in ESS: the format is Website's, and `ess/` models assertion collection only
  (story body, `## Spec first`).
- Commits authorised: the opening store commit, one unit commit, its merge into
  `wave/2026-10-07-w1`, the closing store commit, and one bot pull request to `main`.
